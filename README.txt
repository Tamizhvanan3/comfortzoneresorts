# Comfort Zone Resort — Ooty

A responsive resort landing page built with:
- HTML5
- CSS3
- Bootstrap 5.3
- Bootstrap Icons
- Vanilla JavaScript

## Files
- `index.html` — page structure/content
- `style.css` — complete visual styling
- `script.js` — navbar, scroll reveal, date validation, testimonial carousel support and back-to-top
- `cz-logo.png` — supplied Comfort Zone Resort logo

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Important
The booking form is front-end only. Connect it to your actual booking/availability API or backend before using it for real reservations.

The image URLs are remote Unsplash images. Replace them with your own resort photographs before publishing for the final website.
